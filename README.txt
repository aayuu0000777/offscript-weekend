OFFSCRIPT STANDALONE WEBSITE

This is an independent static website. It does not need Odoo, a database, or an account.

OPEN IT
1. Extract the ZIP file to a folder.
2. Open index.html in a browser.
3. Use the top menu to visit Home, Weekend Planner, Explore Cities, How It Works, and About Offscript.

PUBLISH IT ONLINE
Upload the extracted folder to a static website host such as Netlify, GitHub Pages, or Vercel. Keep the HTML files and the assets folder together. The homepage file is index.html.

WHAT IS INCLUDED
- Separate Home and Weekend Planner pages, plus Explore Cities, How It Works, and About.
- A Bhopal directory with 74 listings across nature/walks, sports, sunset spots, cafés, heritage, and nearby day trips.
- Search, category, time, companion, indicative budget filters, source links, and Google Maps search links.
- Other typed cities show a Google Maps search instead of displaying Bhopal listings.

PLACE DETAILS
Listings link to the tourism, government, venue, or directory source used for the entry. They are not a live check of opening status, public access, activity availability, exact gate, price, or hours. Confirm current details with the place before visiting. Budget labels are indicative where a source provides a clue; otherwise the page says to check before visiting. Nearby day trips are labelled separately.

EDITING
The visible place list is in assets/places.js. Visual styles are in assets/styles.css and assets/pages.css. The pages are plain HTML, CSS, and JavaScript.
